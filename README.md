# Avalos Epoxy Floor

Premium architectural and high-performance epoxy flooring web application built with React, Vite, and Tailwind CSS.

## Features
- **Hero Video Background**: HD video streaming with mobile autoplay support.
- **Architectural Project Portfolio**: 12+ high-definition flooring projects (Epoxy Flake, Quartz Broadcast, Solid Metallic, Metallic Showroom).
- **Zero-Popup Policy**: Clean inline expanding project specifications and direct contact channels.
- **Meet Jose Avalos**: Direct ownership & master craftsman section with authentic 1080p photography.
- **Direct WhatsApp Booking**: Direct messaging link configured for client estimates.
- **Cookie & Privacy Policy**: Non-intrusive compliance banner with local persistence.
- **Favicon**: Branded geometric architectural floor emblem.

## Getting Started

### Prerequisites
- Node.js (v18 or later recommended)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
